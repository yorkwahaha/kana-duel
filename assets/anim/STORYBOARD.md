# 墨域言靈闘場 · 大招分鏡規格

**總長目標：** 影片 **6.0s**（滿動態、滿張力）  
**格式建議：** 720×1080（或等比），24fps，H.264 mp4＋AAC，`+faststart`  
**音訊鐵律：** **不要配樂／BGM**；只留 **喊招人聲＋打擊／特效音**  
**共同風格：** 2.5D 動畫格鬥、墨筆飛白、強光影；**不要寫實真人**；少雜訊碎光  
**共同鏡頭語言：** 砸鏡特寫 → 高速連打／連斬 → 終撃衝擊 → 極短定格（≤0.6s）

輸出檔名：

- `assets/anim/{ao,rin,ya,go,ran,gen,sho,yo}-cast.mp4`

---

## 共用時間軸（6.0s）

| 秒 | 節拍 | 所有角色共通功能 |
|----|------|------------------|
| 0.00–0.55 | **起手衝擊** | smash zoom／入場一擊；立刻有速度感 |
| 0.55–1.40 | **連段預熱** | 2–3 次短促攻擊或蓄勢打擊（非慢鏡頭沉思） |
| 1.40–2.20 | **喊招** | 唸必殺名（約 0.6–1.0s）；動作不中斷 |
| 2.20–4.40 | **連打高潮** | 6–8 段高速命中：impact flash＋hit-stop＋motion blur |
| 4.40–5.50 | **終撃** | 大範圍收束一擊＋畫面震動／撕裂 |
| 5.50–6.00 | **極短定格** | ≤0.6s 英雄定格，方便接 CSS 餘韻 |

**遊戲內餘韻（約 2.8s，程式已做）：** 全螢幕墨爆／線紋掃過＋SFX；不必再進影片。

## 第 1 期

### 1. 墨切・蒼 —『一筆断空』

**主題色：** 墨青／靛黑　**武器：** 墨刃太刀  
**臺詞：**「一筆断空！」  
**節奏：** 拔刀→短斬連段→橫斬裂空→一筆斷空終撃  
**SFX：** 刀鳴／筆觸摩擦／空間撕裂（無人聲以外配樂）

### 2. 焔詠・燐 —『焦言劫火』

**主題色：** 赤／橙金　**手段：** 掌中言靈焰輪  
**臺詞：**「焦言劫火！」  
**節奏：** 合掌點燃→火柱連打→焰輪前推→火幕終撃  
**SFX：** 燃爆／誰聲／焦裂

### 3. 霜鈴・夜 —『千鈴凍結』

**主題色：** 霜青／銀白　**道具：** 手鈴＋腰鈴  
**臺詞：**「千鈴凍結！」  
**節奏：** 暴力振鈴→音波冰刃連射→冰刺環生→冰輪爆散  
**SFX：** 疊鈴／冰裂／粉碎（非慢飄雪）

### 4. 雷拳・轟 —『轟鳴崩拳』

**主題色：** 紫電／暗灰　**手段：** 雙拳雷纏  
**臺詞：**「轟鳴崩拳！」  
**節奏：** 雙拳點燃→衝拳連打→雷影突進→直拳破鏡  
**SFX：** 雷擊／拳擊／電弧

## 第 2 期

### 5. 風蹴・嵐 —『嵐脚千刃』

**主題色：** 翡青／風刃　**手段：** 踢技＋風刃  
**臺詞：**「嵐脚千刃！」  
**節奏：** 踏地震波→殘影側步→旋轉踢連打→俯衝終撃  
**SFX：** 破風／踢擊／氣旋

### 6. 影刃・玄 —『墨影千刹』

**主題色：** 紫黑／影　**武器：** 雙墨匕首  
**臺詞：**「墨影千刹！」  
**節奏：** 墨影消失→影分身爆發→交叉連斬→X 終撃  
**SFX：** 金屬 shing／墨撕裂／瞬移 whoosh

### 7. 符筆・章 —『万符封言』

**主題色：** 青墨／朱印　**道具：** 毛筆＋符紙  
**臺詞：**「万符封言！」  
**節奏：** 筆刺墨彈→連筆斬寫→符紙彈幕釘鎖→巨印蓋章  
**SFX：** 筆 sweep／紙張啪嗒／封印重擊  
**注意：** 一手筆、一手符；勿槍式雙手握筆

### 8. 光扇・陽 —『扇華断空』

**主題色：** 金白／鐵扇　**武器：** 單柄鐵扇（tessen）  
**臺詞：**「扇華断空！」  
**節奏：** 開扇金屬 clang→三日月連斬→迴旋光盤→橫斬裂空  
**SFX：** 金屬開扇／斬擊／光切  
**注意：** 只要一把扇；不要長槍

## 產片檢查清單

- [ ] 臉與服裝可對上現有立繪（`assets/characters/{id}.webp`）  
- [ ] 全程 2.5D，無寫實皮膚毛孔、少碎光雜訊  
- [ ] **滿 6 秒動態**；定格 ≤0.6s  
- [ ] **無 BGM／配樂**；僅人聲＋SFX  
- [ ] 無燒錄字幕／浮水印  
- [ ] 檔名正確放入 `assets/anim/`  
- [ ] 建議壓縮：720×1080、CRF≈28、AAC 96k mono、`+faststart`

## 與程式的銜接

遊戲會：

1. 播 mp4（失敗則改播立繪約 3s；喊招／音效應內嵌於影片）  
2. 再播約 2.8s CSS `special-aftermath`  
3. 接著進入 COMBO 連打段  

因此影片結尾請**極短定格**，不要自己做很長的淡出黑場。
