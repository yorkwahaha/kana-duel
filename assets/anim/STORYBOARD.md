# 墨域言靈闘場 · 大招分鏡規格

**總長目標：** 影片 **3.0s**（可微調至 3.5s，硬上限 5s）＋ 遊戲內 CSS／SFX 餘韻 **約 2.8s**  
**格式建議：** 1080×1920 或 1080×1080，24/30fps，H.264 mp4，無必須對白（臺詞另播 `voice/{id}/cast.mp3`）  
**共同風格：** 2.5D 動畫格鬥、墨筆飛白、強光影；**不要寫實真人**  
**共同鏡頭語言：** 起手特寫 → 蓄勢 → 釋放衝擊 → 定格收束（留給 CSS 餘韻接棒）

輸出檔名：
- `assets/anim/ao-cast.mp4`
- `assets/anim/rin-cast.mp4`
- `assets/anim/ya-cast.mp4`
- `assets/anim/go-cast.mp4`

## 共用時間軸（3.0s）

| 秒 | 節拍 | 所有角色共通功能 |
|----|------|------------------|
| 0.00–0.40 | **起手** | 角色半身近景入場，墨域背景暗下，一眼認出是誰 |
| 0.40–1.20 | **蓄勢** | 言靈／屬性能量在手或武器凝聚；節奏壓低 |
| 1.20–2.20 | **釋放** | 必殺名對應的視覺爆發；速度加快、衝擊波／墨濺 |

## 產片檢查清單

- [ ] 臉與服裝可對上現有立繪（`ao/rin/ya/go.webp`）  
- [ ] 全程 2.5D，無寫實皮膚毛孔  
- [ ] 3.0s 左右結束在「可接餘韻」的定格  
- [ ] 畫面中心勿被永久黑塊擋住（餘韻 CSS 還要疊）

- [ ] 檔名正確放入 `assets/anim/`

## 與程式的銜接

遊戲會：

1. 播 mp4（失敗則改播立繪 3s；喊招／音效應內嵌於影片）  
2. 再播約 2.8s CSS `special-aftermath`  
3. 接著進入 COMBO 連打段  

因此影片結尾請**略暗或留呼吸感**，不要自己再做很長的淡出黑場（避免與餘韻重疊變悶）。
